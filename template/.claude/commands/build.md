**CTO lens.** Build: **$ARGUMENTS**

1. **Triage** (`COMPANY.md` §3) and say the tier in one line: Direct, Planned, Full or Parallel, and why.
2. **Recall:** if memory has history on this area (`memory_query`), read it before exploring the code.
3. **Start:** add a row to `STATUS.md` §2 (work, lens, plan path once it exists, state).
4. **Run the tier's Superpowers flow with the defaults in §3:** inline execution, a proportionate plan, the cheapest capable model for any subagent, ownership rules honored, proof at the user's boundary. Questions only the Founder can answer go to `STATUS.md` §1 with your recommendation. Keep going on everything else.
5. **Close:** Full tier gets one `superpowers:requesting-code-review` on the finished change, then fix what it finds. Run the repo's gates and report them honestly: verdict first, gate results, what's left. Move the row to §4 (or §1 if it waits on the Founder) and list next moves in §5.
